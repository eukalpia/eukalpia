# Этап 1: приёмка (город с орбиты)

Дата: 2026-10-12. Снимки: `app/test-results/shots/` (`npm run shots -- orbit-day orbit-night underside skyline`,
плюс `--quality=low` и `--time=night skyline`). Рендер в headless Chromium (SwiftShader), 1280×720, DPR 1.

## Бюджеты кадра

Бюджеты: High ≤ 900 draw calls / ≤ 6 млн треугольников; Low ≤ 300 / ≤ 1,2 млн.

## Что проверено

- `npx vitest run` — все тесты зелёные; `npm run build` — без ошибок TypeScript.
- Снимки без ошибок консоли и шейдеров на High и Low; фолбэк без WebGL (`--no-webgl`) показывает открытку.
- Изменение размера окна до 900×900 меняет буфер рисования; при скрытой вкладке цикл рендера стоит.

## Найдено и исправлено при доводке

- Белая пелена днём: bloom читал HDR-кадр с порогом ниже диффузного белого. Пороги и сила bloom теперь задаются по времени суток.
- Полосы на стеклянных башнях ночью: несовпадение энергии между свечением отдельных окон вблизи и усреднённым вдали.
  Иерархическое усреднение доли горящих окон с правильной дисперсией и согласованностью по этажам.
- Скала снизу выглядела «тарелкой»: обратный порядок обхода треугольников.
- Плоский свет: дневной пресет переведён в золотой час (солнце 18°, тёплый свет).
