# Этап 5: выпуск — обложка README, OG-картинка, новый pages.yml, удаление site/ — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** профиль и сайт показывают новый город: анимированная обложка README и OG-картинка сняты с v2,
GitHub Pages собирает `app/` из исходников, готовая папка `site/` удалена.

**Architecture:** съёмка идёт через отладочный интерфейс `window.__eukalpia`: режим удержания, в котором
цикл рисует только запрошенные кадры с фиксированным шагом времени (облака и машины движутся плавно, сколько
бы ни длился кадр в SwiftShader), и `capture()`, который ставит камеру и возвращает кадр как data URL.
`app/scripts/cover.mjs` — чистые функции сборки и проверки SVG-обложки, их же вызывает CI.
`app/scripts/capture-cover.mjs` снимает обложку, `og.png` и открытку. `app/scripts/notices.mjs` собирает
`THIRD-PARTY-NOTICES.txt` из лицензий пакетов, которые попадают в сборку.

**Tech Stack:** Playwright (SwiftShader), canvas `toDataURL('image/webp')` в браузере (без новых
зависимостей), GitHub Actions (`actions/setup-node`, `upload-pages-artifact`, `deploy-pages`).

**Spec:** `docs/specs/2026-10-12-eukalpia-v2-design.md` (раздел 10, раздел 12 п. 5).

## Global Constraints

- Формат обложки, который проверяет CI (как в v1): ≥ 2 кадров `<image … href="data:image/(jpeg|webp);base64,…">`,
  анимация `step-end`, статичный первый кадр `<use href="#frame-0"/>` для `prefers-reduced-motion` и
  статичных просмотрщиков, без `<text>`, `<foreignObject>`, `<script>`. Размер файла ≤ 4 МБ (v1: 3,56 МБ).
- На кадрах обложки и OG нет интерфейса и подписей районов.
- `og.png` 1200 × 630, `city-cinematic.webp` 1440 × 810 (размеры v1).
- Сборка без source maps; в `app/dist` нет `.map`.
- Сгенерированный код в git не хранится; медиа README (`public/profile-cover.svg`, `public/profile-ascii.svg`)
  остаются в корневом `public/`, `og.png` и `city-cinematic.webp` — в `app/public/`.
- Имя — `Umaraliev Ravshan Rustamjon O'gli` везде, включая уведомления о лицензиях.
- Слияние в `main` (а значит, деплой) — только после одобрения владельца.
